PRÁCTICA 1: CONFIGURACIÓN DE GRUB Y RECUPERACIÓN DE CONTRASEÑA ROOT
-------------------------------------------------------------------------------

1. Editar el archivo de configuración principal de GRUB:
   $ sudo nano /etc/default/grub
   --> Explicación: Abre el editor de texto 'nano' con privilegios de 
       administrador (sudo) para modificar las directivas de arranque del 
       sistema, donde se cambia el valor de 'GRUB_TIMEOUT' a '20'.

2. Actualizar los cambios en el cargador de arranque GRUB:
   * En sistemas basados en Debian/Ubuntu:
     $ sudo update-grub
   * En sistemas basados en RHEL/Red Hat/Fedora:
     $ sudo grub2-mkconfig -o /boot/grub2/grub.cfg
   --> Explicación: Procesa el archivo modificado previamente y regenera el 
       menú de arranque real que lee el equipo al encender para aplicar los 
       20 segundos de espera.

3. Volver a montar el sistema de archivos con permisos de escritura (Modo Rescate):
   # mount -o remount,rw /
   --> Explicación: Se ejecuta tras interrumpir el arranque e iniciar con el 
       parámetro 'init=/bin/bash'. Por defecto, el sistema arranca seguro en 
       modo "solo lectura" (ro); este comando lo cambia a "lectura y escritura" 
       (rw) para poder guardar modificaciones.

4. Cambiar la contraseña del usuario root:
   # passwd root
   --> Explicación: Invoca el asistente interactivo en la terminal para asignar 
       e introducir una nueva contraseña al superusuario administrador (root).

5. Forzar el reetiquetado de contextos de seguridad en SELinux (Mandatorio en Red Hat):
   # touch /.autorelabel
   --> Explicación: Crea un archivo oculto en la raíz que le indica a SELinux, 
       durante el próximo reinicio normal, que debe actualizar las etiquetas de 
       seguridad del archivo de contraseñas modificado fuera del entorno seguro.

6. Reiniciar el sistema de forma forzada desde la shell de emergencia:
   # exec /sbin/init
   --> Explicación: Reemplaza la shell de comandos temporal de bash y carga el 
       proceso de inicialización estándar del sistema operativo para arrancar 
       normalmente.

PRÁCTICA 2: AUTOMATIZACIÓN MEDIANTE SCRIPTS EN BASH
-------------------------------------------------------------------------------
crear un archivo .sh
nano backup.sh
	#!/bin/bash

	# Generar fecha y hora en formato dd-mm-yyyy:hh:mm
	FECHA=$(date +"%d-%m-%Y:%H:%M")

	# Crear la salva comprimida en el directorio actual
	tar -czvf "backup_${FECHA}.tar.gz" "$HOME"

crear otro archivo .sh
nano guardar.sh
	#!/bin/bash

	# Solicitar el nombre del archivo al usuario
	read -p "Ingresa el nombre para el archivo (sin extensión): " NOMBRE_ARCHIVO

	# Ejecutar el comando y guardar la salida en el Escritorio
	ifconfig > "$HOME/Desktop/${NOMBRE_ARCHIVO}.txt" 2>/dev/null || ip a > "$HOME/Desktop/	${NOMBRE_ARCHIVO}.txt"

	echo "Archivo guardado exitosamente en el Escritorio."

asignar permisos de ejecucion y ejecutar
chmod +x backup.sh guardar.sh
./backup.sh
./guardar.sh

PRÁCTICA 3: CONEXIÓN REMOTA SSH Y AUTENTICACIÓN ASIMÉTRICA POR LLAVES
-------------------------------------------------------------------------------

1. Verificar la conectividad básica de red (Desde el CMD de Windows):
   > ping 10.0.0.67
   --> Explicación: Envía paquetes de prueba ICMP desde la máquina física hacia 
       la IP de la máquina virtual para constatar que el modo Puente (Bridge) 
       está respondiendo y que ambos equipos se ven mutuamente.

2. Habilitar, iniciar y verificar el daemon de SSH (Desde la terminal de Linux):
   $ sudo systemctl enable sshd
   $ sudo systemctl start sshd
   $ sudo systemctl status sshd
   --> Explicación: Configura el servicio de SSH para que se levante de forma 
       automática en cada arranque del servidor (enable), arranca el servicio 
       remoto de forma inmediata en segundo plano (start) y muestra el estado 
       operativo actual en tiempo real (status).

3. Conexión SSH tradicional inicial por contraseña (Desde el CMD de Windows):
   > ssh A20252751@10.0.0.67
   --> Explicación: Realiza la primera llamada remota hacia el servidor bajo el 
       usuario 'A20252751'. Al ser la primera vez, almacena el registro del 
       servidor en el host físico y exige el ingreso manual de la contraseña.

4. Generar el par de llaves criptográficas (Desde el CMD de Windows):
   > ssh-keygen -t rsa -b 4096
   --> Explicación: Genera una llave privada y una pública bajo el algoritmo RSA 
       con una longitud robusta de 4096 bits. Al presionar 'Enter' a las peticiones 
       de passphrase, se asegura que no requiera clave para automatizar el login.

5. Visualizar las llaves generadas localmente (Desde el CMD de Windows):
   > dir "%USERPROFILE%\.ssh"
   --> Explicación: Lista el contenido del directorio oculto de configuraciones 
       SSH de Windows para validar la existencia física de 'id_rsa' (llave privada) 
       e 'id_rsa.pub' (llave pública).

6. Transferir e indexar la llave pública en el servidor (Desde el CMD de Windows):
   > type "%USERPROFILE%\.ssh\id_rsa.pub" | ssh A20252751@10.0.0.67 "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
   --> Explicación: Comando compuesto de alta eficiencia:
       - 'type': Lee la llave pública en Windows.
       - '|': Envía la llave a través del túnel SSH directo al servidor.
       - 'mkdir -p ~/.ssh && chmod 700 ~/.ssh': Crea la carpeta de llaves en 
         Linux y restringe el acceso absoluto a otros usuarios.
       - 'cat >> ~/.ssh/authorized_keys': Agrega la clave de Windows al archivo 
         de llaves autorizadas en el servidor.
       - 'chmod 600 ~/.ssh/authorized_keys': Otorga permisos estrictos de lectura 
         y escritura única al propietario, requisito mandatorio para habilitar 
         el inicio de sesión automático.

7. Validación de acceso directo automático sin contraseña (Desde el CMD de Windows):
   > ssh A20252751@10.0.0.67
   --> Explicación: Comando final de ejecución. Al estar indexada la llave, 
       las máquinas realizan un intercambio criptográfico transparente, permitiendo 
       el acceso directo a la consola de Red Hat sin solicitar credenciales.

PRACTICA 1: GRUB Y RECUPERACIÓN DE ROOT

1. nano /etc/default/grub

Explicación: Abre el editor de texto nano para modificar las variables globales del cargador de arranque GRUB.

Parámetros/Opciones principales:

<ruta_al_archivo>: Ruta del archivo que se desea editar (/etc/default/grub).

-B: Crea una copia de respaldo del archivo al guardar.

-R: Abre el archivo en modo solo lectura.

Comandos y herramientas alternativas recomendadas:

vim /etc/default/grub: Editor de texto avanzado directamente en consola.

sed -i 's/GRUB_TIMEOUT=.*/GRUB_TIMEOUT=20/' /etc/default/grub: Modifica el valor directamente sin entrar al editor interactivo.

2. grub2-mkconfig -o /boot/grub2/grub.cfg

Explicación: Genera el archivo definitivo de configuración de GRUB en base a las variables definidas en /etc/default/grub.

Parámetros/Opciones principales:

-o <ruta>: Especifica la ruta del archivo de salida donde se guardará la configuración generada.

Comandos y herramientas alternativas recomendadas:

grub2-editenv list: Muestra la entrada de kernel seleccionada por defecto en GRUB.

grubby --info=ALL: Muestra los parámetros de arranque actuales configurados en todos los kernels instalados.

3. grep GRUB_TIMEOUT /etc/default/grub

Explicación: Busca e imprime las líneas que coincidan con la cadena especificada dentro de un archivo.

Parámetros/Opciones principales:

-i: Ignora diferencias entre mayúsculas y minúsculas.

-n: Muestra el número de línea donde se encontró la coincidencia.

-v: Invierte la búsqueda, mostrando las líneas que no coinciden.

Comandos y herramientas alternativas recomendadas:

cat /etc/default/grub | grep TIMEOUT: Visualiza el contenido filtrado mediante tuberías.

4. mount -o remount,rw /sysroot

Explicación: Vuelve a montar la partición raíz del sistema en el entorno de emergencia con permisos de escritura.

Parámetros/Opciones principales:

-o <opciones>: Define las opciones del montaje. remount reaplica opciones sin desmontar; rw asigna lectura y escritura; ro asigna solo lectura.

Comandos y herramientas alternativas recomendadas:

mount -t <tipo>: Especifica el sistema de archivos (xfs, ext4).

5. chroot /sysroot

Explicación: Cambia el directorio raíz del proceso actual al directorio especificado, aislando el sistema de archivos real.

Parámetros/Opciones principales:

<directorio>: Ruta que pasará a actuar como la nueva raíz /.

Comandos y herramientas alternativas recomendadas:

exit: Abandona la jaula de chroot y regresa a la shell previa.

6. passwd root

Explicación: Actualiza la contraseña del usuario indicado en el sistema.

Parámetros/Opciones principales:

<usuario>: Nombre de la cuenta a modificar.

-l: Bloquea la cuenta impidiendo el acceso.

-u: Desbloquea la cuenta.

-e: Fuerza la expiración de la contraseña para que el usuario la cambie en el próximo inicio.

Comandos y herramientas alternativas recomendadas:

echo "nueva_clave" | passwd --stdin root: Asigna la contraseña sin interactividad.

7. touch /.autorelabel

Explicación: Crea un archivo vacío en el directorio raíz para notificar a SELinux que debe reetiquetar los archivos del sistema al reiniciar.

Parámetros/Opciones principales:

-c: No crea el archivo si ya existe.

-m: Modifica únicamente la fecha de última alteración del archivo.

Comandos y herramientas alternativas recomendadas:

restorecon -Rv /etc/shadow: Restaura manualmente las etiquetas de SELinux en el archivo de contraseñas.

PRACTICA 2: SCRIPTS EN BASH (BACKUP TAR E IFCONFIG)

1. date +"%d-%m-%Y:%H:%M"

Explicación: Imprime o da formato a la fecha y hora actual del sistema.

Parámetros/Opciones principales:

+"<formato>": Define el patrón de salida (%d día, %m mes, %Y año de 4 dígitos, %H hora en formato 24h, %M minutos).

-u: Muestra la hora en tiempo universal coordinado (UTC).

Comandos y herramientas alternativas recomendadas:

timedatectl: Consulta y cambia la zona horaria del sistema.

2. tar -czvf "backup.tar.gz" "$HOME"

Explicación: Empaqueta y comprime un conjunto de archivos o directorios.

Parámetros/Opciones principales:

-c: Crea un nuevo archivo de respaldo (archive).

-z: Filtra el archivo a través del algoritmo de compresión gzip.

-v: Muestra de forma detallada (verbose) la lista de archivos procesados.

-f: Especifica el nombre del archivo resultante.

-j: Comprime usando bzip2 en lugar de gzip (mayor compresión, más lento).

-J: Comprime usando xz (máximo nivel de compresión).

-x: Extrae los archivos del paquete.

Comandos y herramientas alternativas recomendadas:

zip -r backup.zip $HOME: Crea un comprimido en formato ZIP de forma recursiva.

rsync -avz $HOME /ruta/destino: Copia incremental y sincronización eficiente de archivos.

3. read -p "Mensaje" NOMBRE_VARIABLE

Explicación: Captura una entrada de texto por teclado durante la ejecución de un script en Bash.

Parámetros/Opciones principales:

-p: Muestra el texto de solicitud antes de leer la entrada.

-s: Oculta los caracteres ingresados (ideal para contraseñas).

-t <segundos>: Establece un tiempo límite para ingresar los datos.

Comandos y herramientas alternativas recomendadas:

select: Crea menús de selección numerados de forma interactiva en Bash.

4. ip a

Explicación: Muestra las interfaces de red, direcciones IP asignadas y estados del enlace.

Parámetros/Opciones principales:

-c: Muestra la salida con colores destacados.

-4: Filtra y muestra solo direcciones IPv4.

-6: Filtra y muestra solo direcciones IPv6.

Comandos y herramientas alternativas recomendadas:

nmcli device show: Detalla la configuración de red gestionada por NetworkManager.

ifconfig: Comando heredado para ver y editar la configuración de red.

5. chmod +x script.sh

Explicación: Modifica los permisos de acceso de un archivo o directorio.

Parámetros/Opciones principales:

+x: Añade permiso de ejecución a todos los usuarios.

755: Asigna permisos de lectura/escritura/ejecución al propietario, y lectura/ejecución al resto.

-R: Aplica el cambio de permisos recursivamente a todos los archivos dentro de un directorio.

Comandos y herramientas alternativas recomendadas:

chown usuario:grupo archivo: Cambia el propietario y grupo de un archivo.

PRACTICA 3: RED BRIDGED Y SSH CON LLAVES

1. ping <IP_HOST>

Explicación: Envía paquetes ICMP ECHO_REQUEST a hosts de red para comprobar la alcance y latencia.

Parámetros/Opciones principales:

-c <número>: (Linux) Limita la cantidad de paquetes enviados.

-n <número>: (Windows) Especifica el número de solicitudes enviadas.

-t: (Windows) Envía paquetes de forma ininterrumpida hasta detenerlo con Ctrl+C.

Comandos y herramientas alternativas recomendadas:

traceroute <IP> / tracert <IP>: Traza la ruta que siguen los paquetes en la red.

nc -zv <IP> <PUERTO> / Test-NetConnection: Verifica la apertura de un puerto de red específico (por ejemplo, el puerto 22 para SSH).

2. systemctl enable --now sshd

Explicación: Controla el sistema y los servicios de la plataforma init systemd.

Parámetros/Opciones principales:

enable: Configura el servicio para que inicie automáticamente en el arranque.

--now: Arranca el servicio inmediatamente en el momento de ejecutar el comando.

status: Muestra el estado operativo actual, logs y el PID del servicio.

restart: Reinicia el demonio del servicio.

Comandos y herramientas alternativas recomendadas:

journalctl -u sshd -f: Muestra los registros y logs en tiempo real producidos por el servicio SSH.

3. firewall-cmd --add-service=ssh --permanent

Explicación: Gestiona la configuración del cortafuegos de Linux en tiempo de ejecución.

Parámetros/Opciones principales:

--add-service=<servicio>: Habilita el tráfico entrante para un servicio definido.

--add-port=<puerto/protocolo>: Abre un puerto específico (ejemplo: --add-port=22/tcp).

--permanent: Guarda los cambios de forma persistente entre reinicios.

--reload: Recarga las reglas activas para aplicar los cambios guardados sin reiniciar la red.

Comandos y herramientas alternativas recomendadas:

firewall-cmd --list-all: Lista las reglas del cortafuegos aplicadas en la zona activa.

4. ssh-keygen -t rsa -b 4096

Explicación: Herramienta para generar, administrar y convertir llaves de autenticación SSH.

Parámetros/Opciones principales:

-t <tipo>: Define el algoritmo de cifrado (rsa, ed25519, ecdsa).

-b <bits>: Especifica la longitud en bits de la llave (4096 bits para mayor seguridad en RSA).

-f <ruta>: Especifica el nombre y ubicación del archivo que guardará la llave.

-N "": Asigna una frase de paso (passphrase) directamente desde el comando.

Comandos y herramientas alternativas recomendadas:

ssh-keygen -t ed25519: Crea llaves basadas en curvas elípticas, más seguras y eficientes.

5. ssh usuario@<IP_DEL_SERVIDOR>

Explicación: Inicia un cliente de shell segura en un servidor remoto.

Parámetros/Opciones principales:

-i <ruta_llave_privada>: Apunta a una clave privada específica si no se utiliza el nombre por defecto (id_rsa).

-p <puerto>: Define el puerto de conexión si el servidor no utiliza el puerto estándar 22.

-v: Activa el modo verbose para depurar fallos en el proceso de autenticación.

Comandos y herramientas alternativas recomendadas:

scp archivo.txt usuario@IP:/ruta: Copia archivos hacia o desde un servidor de forma cifrada mediante SSH.

ssh-copy-id usuario@IP: Comando nativo en Linux/Mac para copiar automáticamente la clave pública al servidor remoto sin requerir comandos de PowerShell o comandos complejos.
