Practica 1: Instalacion y configuracion de Docker
==================================================

acordate de habilitar los puertos en tu platadorma de cloud 

sudo dnf config-manager --add-repo https://download.docker.com/linux/rhel/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker

sudo docker pull nginx

sudo mkdir -p /home/website
echo "<h1>Angelo Marcelo Cerda Javier - 2025-2751</h1>" | sudo tee /home/website/index.html

sudo docker run -d \
  --name nginx-web \
  -p 8888:80 \
  -v /home/website:/usr/share/nginx/html:Z \
  nginx

sudo firewall-cmd --add-port=8888/tcp --permanent
sudo firewall-cmd --reload

Practica 2: Instalacion de Portainer
====================================

sudo docker volume create portainer_data

sudo docker run -d \
  -p 8000:8000 \
  -p 9443:9443 \
  --name portainer \
  --restart=always \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:latest

sudo firewall-cmd --add-port=9443/tcp --permanent
sudo firewall-cmd --reload

busca setup token para poder iniciar sesion
sudo docker logs portainer | grep "setup token"

entra a tu ip con el puerto 9443

Paso 3: Acceder a Portainer e inicializar la cuenta
Abre el navegador web e ingresa utilizando la IP de tu servidor (o localmente si estás dentro de un entorno de escritorio):

Localmente: [https://127.0.0.1:9443](https://127.0.0.1:9443)

Desde tu máquina anfitriona/red: [https://10.0.0.105:9443](https://10.0.0.105:9443) (o [https://10.0.0.200:9443](https://10.0.0.200:9443))

Nota: El navegador emitirá una advertencia de seguridad SSL/TLS (certificado autofirmado). Acepta la advertencia para continuar.

En la pantalla inicial de Portainer:

Crea el usuario administrador (admin) e ingresa una contraseña segura de al menos 12 caracteres.

Haz clic en la opción de la izquierda: Get Started (Proceed using the local environment which Portainer is running in).

Esto te conectará directamente al motor de Docker local de tu servidor para completar los pasos finales de la práctica:

Haz clic en el entorno local que aparecerá en pantalla.

Ve a la sección Containers en el menú de la izquierda.

Selecciona el contenedor de NGINX (nginx-web).

Presiona el botón Stop para detenerlo.

Abre una pestaña nueva e ingresa a [http://10.0.0.105:8888](http://10.0.0.105:8888) (o 127.0.0.1:8888) para verificar y tomar la captura donde se confirme que el sitio ya no está accesible.

Practica #3: IDespliegue de contenedor de Wordpress utilizando Docker-Compose
=============================================================================

sudo docker compose version

mkdir -p ~/wordpress-compose && cd ~/wordpress-compose

nano docker-compose.yml
version: '3.8'

services:
  db:
    image: mysql:8.0
    container_name: wordpress_db
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: RootPassword123!
      MYSQL_DATABASE: wordpress_db
      MYSQL_USER: wp_user
      MYSQL_PASSWORD: WpPassword123!
    volumes:
      - db_data:/var/lib/mysql

  wordpress:
    image: wordpress:latest
    container_name: wordpress_app
    restart: always
    ports:
      - "8080:80"
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_NAME: wordpress_db
      WORDPRESS_DB_USER: wp_user
      WORDPRESS_DB_PASSWORD: WpPassword123!
    depends_on:
      - db
    volumes:
      - wp_data:/var/www/html

volumes:
  db_data:
  wp_data:

sudo firewall-cmd --add-port=8080/tcp --permanent
sudo firewall-cmd --reload

sudo docker compose up -d

sudo docker compose ps

Una vez que cargas la página de WordPress en tu navegador (ej. [http://10.0.0.105:8080](http://10.0.0.105:8080)), debes seguir estos pasos para completar la instalación inicial requerida por la práctica:

Paso 1: Seleccionar el idioma

Elige Español (o English) en la lista inicial.

Haz clic en Continuar (Continue).

Paso 2: Formulario de configuración del sitio
Completa los campos con tus datos:

Título del sitio: Escribe un nombre para tu proyecto (ej. Sitio Web - Angelo Cerda).

Nombre de usuario: Crea un usuario administrador (ej. admin o tu nombre).

Contraseña: Asigna una contraseña segura y guárdala.

Tu correo electrónico: Ingresa tu dirección de correo electrónico.

Visibilidad en motores de búsqueda: Puedes dejar la casilla desmarcada.

Paso 3: Finalizar la instalación

Haz clic en el botón Instalar WordPress.

Aparecerá el mensaje de confirmación "¡Logrado!" / "Success!".

Paso 4: Iniciar sesión

Presiona el botón Acceder e ingresa con el usuario y la contraseña que creaste.

Accederás al panel de administración (Dashboard) de WordPress, lo que confirma que tanto la aplicación como la base de datos MySQL están funcionando correctamente.

Para dejar constancia de la entrega de la práctica o personalizar el sitio según las indicaciones de tu clase, realiza los siguientes pasos finales:

1. Publicar una entrada o editar la portada con tu información

En el menú lateral izquierdo, ve a Entradas > Añadir nueva entrada.

Coloca como título: Práctica 3 - WordPress con Docker Compose.

En el cuerpo del contenido, escribe tus datos personales (Nombre y Matrícula).

Haz clic en el botón superior derecho Publicar.

2. Ver tu sitio desplegado en producción

En la barra superior negra, pasa el cursor sobre el icono de la casa o el nombre de tu sitio y haz clic en Visitar el sitio (o abre [http://10.0.0.105:8080](http://10.0.0.105:8080) en una pestaña de incógnito).

Confirma que tu publicación aparezca en la página principal.
