======
EXTRAS
======

Práctica 1: Gestión de paquetes y repositorios (dnf)
Comando principal: dnf check-update / dnf upgrade

Variantes y parámetros:

sudo dnf update --refresh: Fuerza a actualizar la caché de los repositorios antes de verificar actualizaciones.

sudo dnf upgrade --security: Aplica únicamente las actualizaciones marcadas como parches de seguridad critical/important.

sudo dnf upgrade-to <paquete>-<versión>: Actualiza o degrada un paquete específico a una versión exacta.

sudo dnf update --exclude=<paquete>: Actualiza todo el sistema excluyendo un paquete específico (ej. dnf upgrade --exclude=kernel).

Comando principal: dnf repolist

Variantes y parámetros:

sudo dnf repolist --all: Muestra todos los repositorios configurados en el sistema, tanto los habilitados como los deshabilitados.

sudo dnf repoinfo <repo_id>: Muestra información detallada sobre un repositorio (URL base, fecha de última actualización, estado).

sudo dnf config-manager --set-enabled <repo_id>: Habilita un repositorio específico sin editar manualmente archivos en /etc/yum.repos.d/.

sudo dnf config-manager --set-disabled <repo_id>: Deshabilita un repositorio.

Comando principal: dnf search / dnf install

Variantes y parámetros:

dnf search all <término>: Busca la palabra clave no solo en el nombre del paquete, sino también en las descripciones completas.

dnf provides <archivo_o_comando> o dnf whatprovides <comando>: Identifica qué paquete proporciona un archivo ejecutable o librería que falta (ej. dnf provides */bashtop).

dnf info <paquete>: Muestra versión, licencias, tamaño y resumen detallado de un paquete antes de instalarlo.

sudo dnf install --downloadonly <paquete>: Descarga los paquetes RPM y sus dependencias al disco sin llegar a instalarlos.

Comando principal: dnf remove / dnf autoremove

Variantes y parámetros:

sudo dnf remove --duplicates: Elimina versiones antiguas duplicadas de paquetes que no se limpiaron correctamente.

sudo dnf history: Muestra el historial completo de operaciones de instalación, actualización y remoción realizadas en el sistema.

sudo dnf history undo <ID_de_transacción>: Revierte completamente los cambios aplicados en una transacción previa específica (desinstala lo que se instaló o viceversa).

Comandos recomendados complementarios para la Práctica 1:

rpm -qa: Lista absolutamente todos los paquetes RPM instalados en el sistema operativo.

rpm -ql <paquete>: Lista todos los archivos individuales y rutas que instaló un paquete concreto.

dnf clean all: Elimina la memoria caché de metadatos e imágenes RPM para liberar espacio o resolver problemas de sincronización de repositorios.

Práctica 2: Automatización y tareas programadas (cron y at)
Comando principal: crontab

Variantes y parámetros:

crontab -l: Lista las tareas programadas activas para el usuario actual sin abrir el editor.

sudo crontab -u <usuario> -e: Permite al administrador editar la tabla de cron perteneciente a otro usuario del sistema.

crontab -r: Elimina completamente el archivo crontab del usuario actual (borra todas las tareas).

crontab -i -r: Pide confirmación interactiva antes de eliminar el archivo crontab.

Sintaxis y variantes de tiempo en Cron:

@reboot /ruta/comando: Ejecuta la tarea una sola vez durante la secuencia de arranque del sistema.

@daily o @midnight (equivalente a 0 0 * * *): Ejecuta la orden todos los días a medianoche.

*/15 * * * *: Ejecuta una tarea en intervalos recurrentes (en este caso, cada 15 minutos).

Comando principal: at y atd

Variantes y parámetros:

atq: Muestra la lista/cola de trabajos pendientes programados con at.

atrm <ID_trabajo>: Elimina un trabajo específico de la cola de ejecución según su identificador numérico.

at -c <ID_trabajo>: Muestra las variables de entorno y el script exacto que se ejecutará en ese trabajo.

at -f /ruta/script.sh 14:30: Programa la ejecución de un archivo script existente para una hora específica.

Comandos recomendados complementarios para la Práctica 2:

systemctl status crond: Verifica que el demonio principal de cron esté activo en el sistema.

systemctl status atd: Revisa el estado de ejecución del servicio secundario para tareas at.

systemd-run --on-calendar="2026-08-11 11:00:00" <comando>: Alternativa moderna nativa de Systemd (systemd.timer) que reemplaza a cron y at en distribuciones empresariales como RHEL.

Práctica 3: Gestión de discos, particiones y puntos de montaje
Comando principal: lsblk

Variantes y parámetros:

lsblk -f: Muestra la lista de bloques junto con el sistema de archivos (ext4, xfs, etc.), UUID y punto de montaje actual.

lsblk -m: Muestra la estructura de discos detallando permisos, propietario y grupo de cada dispositivo.

fdisk -l /dev/sdb o parted /dev/sdb print: Inspecciona la tabla de particiones (MBR o GPT) existente en un dispositivo físico o virtual específico.

Comando principal: mkfs (Formateo)

Variantes y parámetros:

sudo mkfs.xfs /dev/sdb: Formatea la unidad utilizando XFS, el sistema de archivos nativo y por defecto en Red Hat Enterprise Linux.

sudo mkfs.ext4 -L "MI_DISCO" /dev/sdb: Asigna una etiqueta de volumen (label) al disco durante el formateo.

sudo mkfs.ext4 -b 4096 /dev/sdb: Define un tamaño de bloque personalizado en bytes para la estructura del disco.

Comando principal: mount / umount

Variantes y parámetros:

sudo mount -o ro /dev/sdb /mnt: Monta la unidad en modo únicamente de sólo lectura (read-only), impidiendo modificaciones o escrituras.

sudo mount -a: Intenta montar todos los sistemas de archivos declarados en el archivo estático /etc/fstab.

sudo umount -l /punto_montaje: Desmontaje diferido (lazy unmount). Desconecta el sistema de archivos inmediatamente de la jerarquía, resolviendo bloqueos si la carpeta está siendo utilizada por algún proceso.

sudo umount -f /punto_montaje: Fuerza el desmontaje (force) en caso de unidades no disponibles o de red (NFS).

Comandos recomendados complementarios para la Práctica 3:

df -hT: Muestra el espacio ocupado y disponible en todos los puntos de montaje, indicando de forma explícita el tipo de sistema de archivos (-T) en formato legible por humanos (-h).

fuser -mv /punto_montaje o lsof +D /punto_montaje: Identifica exactamente qué procesos o usuarios están bloqueando un directorio e impidiendo que se pueda desmontar con umount.

blkid /dev/sdb: Obtiene el código UUID único del dispositivo de almacenamiento, necesario para configurar montajes automáticos permanentes tras reinicios dentro del archivo /etc/fstab.
