reiniciar servicio para habilitar los cambios

Práctica 1: Servidor Web Apache (httpd)
Comandos clave y sus parámetros
dnf install -y <paquete>

install: Descarga e instala los paquetes indicados.

-y: Responde "sí" automáticamente a todas las confirmaciones.

systemctl enable --now <servicio>

enable: Configura el servicio para que inicie automáticamente con el sistema.

--now: Inicia el servicio inmediatamente sin tener que ejecutar start por separado.

semanage port -a -t http_port_t -p tcp <puerto>

-a: Añade una regla a la política de SELinux.

-t http_port_t: Define el tipo de contexto de puerto (en este caso, puertos autorizados para servidores web).

-p tcp: Especifica el protocolo de red (TCP).

restorecon -R -v <directorio>

-R: Aplica el cambio de contexto de seguridad de SELinux de forma recursiva a todos los subdirectorios y archivos.

-v: Muestra en pantalla los archivos cuyo contexto ha sido restaurado.

firewall-cmd --permanent --add-port=<puerto>/tcp

--permanent: Guarda la regla en el almacenamiento persistente para que no se pierda al reiniciar.

--add-port: Abre un puerto específico especificando puerto y protocolo.

Recomendaciones de código para Práctica 1
Bash
# Instalación e inicio rápido de Apache
sudo dnf install -y httpd && sudo systemctl enable --now httpd

# Creación de estructura de directorios en una sola línea
sudo mkdir -p /var/www/{site1,site2}

# Configuración limpia del VirtualHost (escuchando en 80 y 8080)
cat <<'EOF' | sudo tee /etc/httpd/conf.d/virtualhosts.conf
Listen 8080

<VirtualHost *:80>
    DocumentRoot "/var/www/site1"
    <Directory "/var/www/site1">
        Require all granted
    </Directory>
</VirtualHost>

<VirtualHost *:8080>
    DocumentRoot "/var/www/site2"
    <Directory "/var/www/site2">
        Require all granted
    </Directory>
</VirtualHost>
EOF

# Reglas de red y SELinux requeridas
sudo semanage port -a -t http_port_t -p tcp 8080
sudo restorecon -R -v /var/www/
sudo firewall-cmd --permanent --add-port={80,8080}/tcp && sudo firewall-cmd --reload
sudo apachectl configtest && sudo systemctl restart httpd
Práctica 2: Servidor de Correo Postfix (SMTP Relay)
Comandos clave y sus parámetros
postconf -e "<parametro> = <valor>"

-e: Edita o añade la directiva especificada directamente en el archivo /etc/postfix/main.cf de forma segura.

postmap <tipo>:<archivo>

<tipo>: Tipo de base de datos (lmdb para Red Hat 10, reemplaza al antiguo hash).

<archivo>: Archivo de texto plano con los mapeos (ej. usuarios/contraseñas) para compilarlo en formato binario legible por Postfix.

journalctl -u <servicio> -n <lineas> --no-pager

-u: Filtra los registros por una unidad de systemd específica.

-n: Especifica el número de líneas recientes a mostrar.

--no-pager: Imprime la salida directamente en la terminal sin abrir un paginador (less).

Práctica 3: Servidor de Impresión CUPS (Impresora PDF)
Comandos clave y sus parámetros
lpadmin -p <nombre> -v <dispositivo> -E -m <controlador>

-p: Asigna un nombre descriptivo a la impresora.

-v: Especifica la URI del dispositivo (ej. cups-pdf:/).

-E: Habilita y acepta trabajos en la cola de impresión de manera inmediata.

-m: Selecciona el archivo de controlador PPD a utilizar (usar CUPS-PDF.ppd para evitar advertencias de depreciación raw).

lpstat -p <nombre> -l

-p: Revisa el estado de una impresora específica.

-l: Muestra una salida detallada en formato largo.

setsebool -P <booleano> <valor>

-P: Aplica el cambio de la regla booleana de SELinux de forma permanente (persiste tras reinicios).

<valor>: 1 o on para activar la regla.

Recomendaciones de código para Práctica 3
Bash
# Instalación de CUPS y módulo PDF
sudo dnf install -y cups cups-pdf && sudo systemctl enable --now cups

# Configuración de permisos de acceso en cupsd.conf
sudo sed -i 's/Listen localhost:631/Listen *:631/' /etc/cups/cupsd.conf
sudo cupsctl --share-printers --remote-admin --remote-any

# Creación de la impresora con el controlador nativo PPD
sudo lpadmin -p Impresora_PDF -v cups-pdf:/ -E -m CUPS-PDF.ppd

# Ajustes de firewall y permisos de SELinux
sudo setsebool -P cups_execmem 1
sudo firewall-cmd --permanent --add-port=631/tcp && sudo firewall-cmd --reload
sudo systemctl restart cups
